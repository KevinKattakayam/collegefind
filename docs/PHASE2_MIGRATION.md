Verified on phase-2-safety-integrity against newly provisioned local PostgreSQL 16 databases only. NOT executed against production. See the final verification entry in UPGRADE_STATUS.md for exact results.

20261117000000_field_evidence_import_runs adds nullable Source identity/publication metadata and new FieldEvidence, EvidenceDecision and ImportRun tables. Existing college IDs/slugs, users, relationships and typed historical records are untouched. No legacy Source rows are merged: their content checksums cannot be established retrospectively. New identical artifacts share a Source identity; different artifacts retain separate Sources.

FieldEvidence holds individual profile claims, source and publication/year/validity scope. Competing claims coexist. supersedesId records history without deleting predecessors; staging checks college/field scope. EvidenceDecision is an append-only service history linked to a current ADMIN user and AuditLog. No new service updates College.dataStatus or summary metrics. Existing financial/admission/ranking tables remain authoritative typed storage; EvidenceDecision also references each existing typed record directly (exactly one target enforced by SQL), so their values are not duplicated; public evidence projection still needs follow-up before enrichment publication.

JoSAA import has an immutable content checksum, source identity and mapping-sensitive run identity. The raw CLI file checksum and rejected-row report are retained. Source/run registration occurs before atomic file writes; exceptions roll back the entire file and mark the run FAILED. Repeating a PUBLISHED run returns its saved summary. PARTIAL runs identify unmatched/rejected rows and may be retried. A conflicting existing cutoff aborts with old history intact; resolve by review, never by silently replacing values. Concurrent serializable conflicts may require explicit retry. Interrupted transactions roll back while the durable STAGED run remains retryable. Non-sensitive failure summaries are persisted; no automatic production retry/deployment is configured.
